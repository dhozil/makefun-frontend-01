# make.fun — Live Arena

A lightweight live competition frontend with session caching and ETag revalidation.

Four surfaces: board `#/`, brief `#/bounty/<slug>`, leaderboard `#/bounty/<slug>/leaderboard`, and competitor profile `#/profile/<handle>`.

Run `node serve.ts` then open http://localhost:8080.
